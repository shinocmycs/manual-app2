# 設定マニュアル GitHub版

iPhoneのGitHub Web画面からアップロードできるようにした軽量構成です。

- 元マニュアル: 129ページ
- PDF分割: 43ファイル（3ページずつ）
- 総ファイル数: 48
- 検索、カテゴリ絞り込み、該当ページジャンプ対応
- 写真・赤枠・黄色注釈は元PDFページをそのまま使用

## アップロード
ZIPをiPhoneの「ファイル」アプリで展開し、
展開したフォルダの中身をすべてGitHubリポジトリのルートにアップロードしてください。
ZIP自体はアップロードしません。

## GitHub Pages
Settings → Pages → Deploy from a branch → main / /(root) → Save
